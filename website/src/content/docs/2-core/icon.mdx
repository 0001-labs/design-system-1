## Attributes

| Attribute | Type | Default | What it does |
| --- | --- | --- | --- |
| `type` | string | Empty | File name from `DS1/x-icon/`, without `.svg`. |
| `variant` | `glyph`, `primary`, `secondary` | `glyph` | Plain drawing or a background treatment. |

Use `type="check"`, not `name="check"`. `size="small"` draws at 12px, `size="large"` at 16px. The drawing follows the system’s `--ds-sf` scale. Use `--ds-icon-color` when a control needs a different ink.

## Accessible labels

A decorative icon beside text can have `aria-hidden="true"`. Give an icon-only button an accessible name on its actual button. A tooltip supplements that name; it is not a replacement for it.

## Source and additions

The source files live in `DS1/x-icon/`. Add missing drawings to that library first, then generate the runtime map and public collection. Products carry the icons they use as local files.

`ds-icon` draws the most common icons at once and loads the rest in one deferred chunk the first time one is asked for. A component that always draws one icon ships that drawing with itself through `provideIcons({ name: svg })`, as `ds-avatar` does with its person, so it never waits for the chunk.

## Flags

Every country has its flag, in `DS1/x-flag/` by its two-letter code in lower case (`ie.svg`, `jp.svg`, `gb-sct.svg` for a nation of the UK), so a page can show where people are from. They are not listed here. Each is 3:2, drawn as an `<img>` with `.ds-flag` from `controls.css`: one control high, 12px with `.ds-flag--small`, corners a quarter of its height, a hairline in the fill's grey on its edge, standing on the line's sixteen with the words 4px after it; in a table row it stands in the middle, clear of the row's lines.

```html
<img class="ds-flag" src="flags/ie.svg" alt=""> Dublin, Ireland
```

A product copies them with Sync 1's `flags` export: `"flags": ["jp", "dk"]`, or `true` for every one when the country is not known in advance. The drawings are country-flag-icons' (MIT, licence beside them); Japan's is Ezo's.

## App logos

Use the original full-colour artwork for app sections and integration cards. These are separate from monochrome interface marks: no recolouring, masking, cropping or added corners. Their source SVGs and attribution live in `DS1/x-app/`. Brand names and marks belong to their owners.

```html
<ds-icon type="app-slack" size="app" aria-hidden="true"></ds-icon>
<span>Slack</span>
<ds-icon type="app-gmail" size="app-large" aria-hidden="true"></ds-icon>
<ds-icon type="app-google-drive" style="--ds-icon-size: 20px" aria-hidden="true"></ds-icon>
```

`size="app"` is 40px (two squares), `size="app-large"` is 60px (three). `--ds-icon-size` sets another size, multiplied by the device scale. Keep the artwork contained in its square; its original aspect ratio stays intact. Beside an app’s written name, hide the decorative logo from assistive technology. When it stands alone, give the containing link or button the app’s name.

Sync 1 copies selected files through the existing icons export: `"icons": ["app-slack", "app-gmail"]`. Components include these names in the deferred icon collection. No other product is migrated by adding this library.
