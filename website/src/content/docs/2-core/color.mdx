`ds-color` draws a native colour field two squares wide and one square high.
The native input owns its platform picker, accessible label, form value,
disabled fieldsets and reset. DS1 owns its border, focus, padding and scale.

```html
<label>Exact colour
  <ds-color><input type="color" name="accent" value="#99ff73" /></ds-color>
</label>
```

React products use `ColorInput` from `DS1/react/choice`. Native input props and
refs pass through. Put layout classes and width on the host. The adapter is safe
to render on the server; register the component before hydrating in the browser.

[`ds-swatch`](/2-core/swatch/) displays a colour sample inside a shared button or beside a label.
It is four fifths of a square, scaled with the surface, fitting within a one-square row.
Its `value` is a CSS colour; `selected` adds a visible selection outline.
It is decorative: give its enclosing button an accessible name and pressed
state, or supply adjacent text. Colour data and saving belong to the product.

```html
<ds-button control="slotted" icon>
  <button type="button" aria-label="Apple green" aria-pressed="true">
    <ds-swatch value="#99ff73" selected aria-hidden="true"></ds-swatch>
  </button>
</ds-button>
```

For an exact hex text entry, compose with `ds-input`. The product validates
its stored colour format and any contrast or permission requirements. Keep
those requirements separate from the native picker and shared visual controls.

## Behaviour

The field is two squares wide and one high, and it fills that box with the input. The colour stands 2px inside a 1px line with the field's corners. A press opens the browser's own picker, and the value and its change events are the input's. `disabled` and a disabled `fieldset` dim the field to half and leave it unpressable.

`ds-color` also works inside a shadow root: it adds its stylesheet to that root once.

## Accessibility

The native input is what assistive technology meets, so it needs a name: a `label` around it, or `aria-label` on it. Focus shows as a 2px ring. Calling `focus()` on `ds-color` moves focus to the input. Never let a colour alone carry a choice: name it in words too.

## API

`ds-color` has no attributes of its own. Set `name`, `value`, `disabled` and the rest on the input.

| Slot | What it holds |
| --- | --- |
| Default | One `input type="color"`. |

It has no events or tokens of its own. Copy `color` through Sync 1. React products use `ColorInput` from `DS1/react/choice`.
