The six layouts of [Page](/4-page/page/), each as a full page.

Pick a layout for what the page is for, not how it looks: each card says when to reach for it. The layout is one attribute on Page, `layout`, and the grid places the navigation, the content and any supporting areas for you. Switch to Phone to see each one on a small screen.

Switch between Computer, Mobile and Tablet, or open an example full size. Changes stay in the preview.
