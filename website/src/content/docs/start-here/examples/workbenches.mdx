Whole tools rather than pages, each filling a computer's window edge to edge. They are drawn [Desktop aligned](/1-root/scaling/#desktop-aligned): the window is a whole number of squares wide and the height's leftover sits above it, so every pane, track and grid line ends on a square. Open one full size and resize the window to see it hold.

The Multitrack puts loops on tracks, one beat a square at the middle zoom. Play, drag a clip along the beats or onto another track, pull its right edge, drag a loop in from the browser, set the loop on the ruler, mix with the faders and edit the selected clip. Space plays; nothing makes a sound but the optional metronome.
