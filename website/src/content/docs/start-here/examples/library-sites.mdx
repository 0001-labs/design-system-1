The same components, each drawn by a different [library](/libraries/): its own paper, accent, corners and type. Each page loads Design system 1, then its library stylesheet. Compare two pages drawn by the same library, such as the Travel magazine and Travel stays in Lagoon, to see what a library keeps the same across different pages. Switch between Computer, Mobile and Tablet, or open an example full size. Changes stay in the preview.
