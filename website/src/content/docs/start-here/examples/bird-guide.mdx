A whole site drawn by the [Birdie library](/libraries/), page by page.

Birdie gives Design system 1 its own paper, green bands, corners and type, while the components underneath stay the same. The pages run from the front page to the catalogue, a species, a place, a watcher and the editorial Field notes, so together they show how one library carries a whole site. Switch between Computer, Mobile and Tablet, or open an example full size. Changes stay in the preview.
