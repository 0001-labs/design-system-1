The same components, each drawn by a different [library](/libraries/): its own paper, accent, corners and type. Each page loads Design system 1, then its library stylesheet. The Slate issue tracker uses a 10px unit for finer spacing, with full-size text and controls. Signal draws both the Deploy console here and the Developer platform in [Library sites](/start-here/examples/library-sites/). Switch between Computer, Mobile and Tablet, or open an example full size. Changes stay in the preview.
