## Using the system fonts

The npm package includes Inter Arrows and Iosevka Extended. It uses a system font for interface text. Import the package stylesheet to load the fonts and typography tokens.

Use `--ds-typeface-regular` for body text, `--ds-typeface-medium` for headings and `--ds-typeface-mono` for code. You can set those tokens to use your own typeface. We plan to develop an original typeface for the system.

### Japanese and Chinese

The language tokens (`--typeface-regular-jp`, `--typeface-regular-zh-hans`, `--typeface-regular-zh-hant`, and `--ds-typeface-regular-jp` and its Chinese pair for the components) name Noto Sans first and then the reader's own faces: Hiragino and PingFang on Apple systems, Yu Gothic, Microsoft YaHei and JhengHei on Windows, Noto Sans CJK on Android and Linux. A page in Japanese or Chinese (`lang="ja"`, `lang="zh"`, Simplified with `zh-Hans`) sets its labels in that language's face. Without anything more, Japanese and Chinese text is drawn in those system faces and nothing is downloaded.

A product that shows Japanese or Chinese and wants Noto Sans everywhere adds `cjk.css` (`DS1/1-root/cjk.css`, Sync 1's `"cjk": true` on `root` or `tokens`). It loads Noto Sans JP, SC and TC from Google Fonts, which cuts each into `unicode-range` slices so a page downloads only the characters it shows, and stops the browser from thickening their one weight (`font-synthesis-weight: none`). Noto Sans is under the SIL Open Font License. A page whose security policy keeps other hosts out leaves `cjk.css` out, or serves Noto Sans itself under the same family names, which the tokens then find.

Olivetti Dot is available here as a specimen; it is not loaded by the system stylesheet. Supernatural has no font asset or typeface token yet.

### Arrows in standalone pages

Inter's 36 supported arrow glyphs are embedded directly in `fonts.css` and `component-tokens.css`. They need no network request or separately copied font file, including when Sync 1 copies tokens alone or disables other fonts. Components keep `"Inter Arrows"` before custom typeface tokens. Characters Inter does not contain still use the remaining font stack.

A standalone HTML file with its own typography can copy or inline `DS1/1-root/inter-arrows.css` from the open-source package, then start every font stack with `"Inter Arrows"`, including headings and code:

```css
body { font-family: "Inter Arrows", "Your text face", sans-serif; }
code { font-family: "Inter Arrows", "Your code face", monospace; }
```

The portable sheet contains only the arrow face and does not change the surrounding typeface. Keep `fonts/Inter-LICENSE.md` with redistributed font assets. `node scripts/fonts/embed-arrows.mjs` regenerates the embedded sheets from the bundled WOFF2; `--check` verifies them. The original outlines were verified against the official Inter 4.1 release.
